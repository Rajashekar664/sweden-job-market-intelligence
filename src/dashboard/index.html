About This Project

The Sweden Job Market Intelligence Platform is a personal data analytics project that explores Swedish job advertisements using data retrieved from the JobTech API.

Python and Pandas handle data collection and cleaning. JavaScript and Chart.js power the interactive dashboard.

The dataset focuses on advertisements matching the search term "data engineer". Results reflect the collected sample, not the entire Swedish labour market.
